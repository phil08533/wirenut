## 1. ADS — Application Data Sheet (filled as Patent Center web form, not the PDF)

| Screen section | Entry |
|---|---|
| Inventor Information | Name, residence, mailing address from block above. One inventor (add co-inventors ONLY if someone else contributed to conception of a claim — incorrect inventorship can invalidate the patent) |
| Correspondence Information | Your email; enable e-notification (fastest, and avoids lost mail) |
| Application Information | Title as above; Entity Status: Micro (or Small); Application type: Nonprovisional |
| Representative Information | LEAVE BLANK (pro se) |
| **Domestic Benefit Information** | **Add row: Continuity Type = "Claims benefit of provisional application (35 U.S.C. 119(e))"; Prior Application Number = [63/XXX,XXX]; Filing Date = [date]** |
| Foreign Priority | None |
| Assignee Information | Leave blank (you own it personally) unless you've formed an LLC and want it as applicant — if so, an assignment must be executed and recorded; simplest path: file as inventor-applicant, assign to the LLC later via Assignment Center |

## 2. Declaration — form PTO/AIA/01

| Field | Entry |
|---|---|
| Title of invention | Exactly as above |
| Application "attached hereto" checkbox | Check "the attached application" (you file the declaration with the application) |
| Inventor name, signature, date | Sign by hand or S-signature: `/Philip Gonzales/` style between slashes, typed by you |
| Warning acknowledgments | Read the two statements (you reviewed the application; duty of candor) — they're the legal teeth of the form |

## 3. Micro entity certification — form PTO/SB/15A (gross income basis)

| Field | Entry |
|---|---|
| Application number / filing date | Leave blank at first filing (unknown yet) — Patent Center associates it |
| First named inventor | Your name |
| Certification statements (4) | You certify: small-entity qualification; ≤4 prior filed applications; income < the current 3×-median threshold (check the number at uspto.gov → micro entity); no obligation to assign to a non-qualifying entity |
| Signature | Same S-signature style |

If you don't meet ANY one of the four → file as **small entity** instead (no form; just select Small on the fee screen). Never claim micro if unsure — improper micro claims can taint the patent; small entity costs only ~$400 more at filing.

## 4. What NOT to file

- No "petition" forms, no extension forms, nothing else — the base package is exactly: Spec+Claims+Abstract (DOCX), Drawings (PDF), ADS (web), Declaration (PDF), SB/15A (PDF), fees.
- Do not use the old EFS-Web or mail filing — Patent Center only ($400 paper-filing penalty otherwise... and yes, that's a real fee).
