# Information Disclosure Statement (IDS) — Candidate References

File on form **PTO/SB/08a** within 3 months of filing (no fee in that window). List everything below that you actually know of; add anything else you've seen (competitor products, videos, forum posts that showed the idea). Disclosing art does NOT hurt you — it strengthens the patent against later challenges; *withholding* known art can render the patent unenforceable.

## How to file

1. Fill PTO/SB/08a (patents/pubs) and SB/08b page (NPL) — fillable PDFs from uspto.gov/forms.
2. For NPL, attach a copy of each document (PDF printout of datasheet pages is fine). US patents don't need copies.
3. Patent Center → your application → "Upload documents" → doc code **IDS** (+ **NPL** for the attachments).
4. Certification section on SB/08: leave blank (not needed inside the free 3-month window).
