# Prototype Images

Photos of the inventor's own prototypes: a standard twist-on wire nut combined with separately purchased heat-shrink tubing (parts from Harbor Freight).

## Originals (use these for filings, test records, and pitches)

| File | Shows |
|---|---|
| `original_lineup_prototypes.jpg` | Yellow (large) and blue (small) wire nuts with shrunk-on black heat-shrink sleeves, next to loose tubing and a lighter used for shrinking. |
| `original_installed_on_zip_cord.jpg` | Yellow wire nut with shrunk-on sleeve over spliced landscape-lighting zip cord, beside a stripped length of the same cord. |

The printed text on the sleeves (e.g. "E203950") is real. It is a UL file number printed by the tubing manufacturer and covers the tubing as a component only. It does NOT mean the finished connector is UL-listed.

## AI-edited versions

`reference_*.jpg` are the originals run through an AI image editor to look like studio shots. Use for mockups only, never for filings, test records, or buyer pitches.
